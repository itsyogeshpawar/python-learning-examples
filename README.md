# Python Learning Examples

This repository is designed to help you learn Python step by step, from basic to advanced concepts. Each example will include detailed explanations and code.

## Structure
- `basics/` — Fundamental Python concepts
- `intermediate/` — More advanced topics
- `advanced/` — Expert-level Python features

## How to Use
1. Start with the `basics/` folder.
2. Read the example, understand the explanation, and try the code yourself.
3. Progress to `intermediate/` and `advanced/` as you learn.

Happy learning!
